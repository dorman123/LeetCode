# 📘 LeetCode Solutions

ברוכים הבאים לפרויקט **LeetCode** – מאגר אישי לפתרונות של בעיות אלגוריתמיות מ-[LeetCode](https://leetcode.com/).  
המטרה היא לשפר מיומנויות פתרון בעיות, לתרגל מחשבה לוגית, ולהתכונן לראיונות עבודה בתחום הפיתוח.

---

## 🧠 תכנים

📂 כל פתרון שמור לפי תקיה המתאימה לרמת הקושי:

- ✅ `easy/` – בעיות קלות  
- ⚠️ `medium/` – בעיות בינוניות  
- 🔥 `hard/` – בעיות קשות  

בכל תקיה מופיעים קבצים עם שם הבעיה, פתרון בקוד Python והסבר (אם רלוונטי).

---

## 🛠️ טכנולוגיות

- 🐍 Python (רוב הפתרונות)
